# Code Clash

A small starter web app built with Node.js, Express, and EJS.

## Requirements

- Node.js 18 or newer
- npm

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. For a non-watching start, use `npm start`.

## Project structure

- `server.js` — Express application and routes
- `views/` — EJS page templates
- `public/` — Static assets such as CSS
